# Failure And Fallback Contracts

This document specifies code paths for recovery, explicit failure reporting,
and low-confidence abstention. Their presence does not establish an accuracy
improvement.

The exact release thresholds come from `configs/paper.json`:

- `foreground.fallback_fraction=0.003`
- `abstention.threshold=0.3`

## Stage-by-stage contract

| Stage | Code link / symbol | Trigger | Observed behavior | Returned metadata / fields | Downstream consequence | Category |
| --- | --- | --- | --- | --- | --- | --- |
| Stage 1 PDF parsing | `src/matdeplot/document_pipeline.py::MinerUPDFParser.parse` | `magic_pdf` (MinerU) is unavailable for a PDF input | Raises `RuntimeError("MinerU is not installed; install it only for PDF inputs")` | No manifest row is written | PDF processing stops immediately | terminal |
| Stage 1 PDF parsing | `src/matdeplot/document_pipeline.py::DocumentPipeline.run` via `MinerUPDFParser.parse` | MinerU parsing raises any exception | The exception propagates | No recovery metadata is added | PDF processing stops immediately | terminal |
| Stage 1 subfigure cropping | `src/matdeplot/document_pipeline.py::crop_subfigures` | `detect_subfigures(...)` returns an empty list | Replaces the empty detector result with one full-image `Box` and writes a single crop | No explicit fallback flag is recorded | Stage 2 still receives one panel instead of zero panels | recovery |
| Stage 1 subfigure cropping | `src/matdeplot/document_pipeline.py::crop_subfigures` | `detect_subfigures(...)` raises | The exception propagates; there is no local rescue path | No recovery metadata is added | Document processing stops immediately | terminal |
| Stage 2 panel classification | `src/matdeplot/document_pipeline.py::DocumentPipeline.run` | `assume_line_charts=True` | Bypasses the hosted classifier and injects a synthetic `PanelClassification` with `chart_type="line chart"` | `classification.reasoning="Classification bypassed by explicit CLI option."`; `first_level="Unknown"`; `second_level="Unknown"`; `confidence=0.0` | Stage 3 runs for every panel without contacting the classifier | explicit bypass |
| Stage 2 panel classification | `src/matdeplot/document_pipeline.py::DocumentPipeline.run` | `assume_line_charts=False` and `self.classifier is None` | Raises `RuntimeError("Stage-2 classifier is required unless --assume-line-charts is set")` | No manifest row is written for the blocked panel | Document processing stops immediately | terminal |
| Stage 2 panel classification | `src/matdeplot/document_pipeline.py::DocumentPipeline.run` | `self.classifier.classify(...)` raises | The exception propagates | No recovery metadata is added | Document processing stops immediately | terminal |
| Stage 3 legend detection | `src/matdeplot/pipeline.py::MatDeplotPipeline.extract` around `detect_legends(...)` | Legend/clutter detection raises | Converts the error into a recorded failure and continues with `legend_boxes=[]` | Appends `FailureRecord(stage="legend_detection", ...)` to `ExtractionResult.failures` | Extraction continues without legend masking | recovery |
| Stage 3 axis detection | `src/matdeplot/detectors.py::detect_axes_with_fallback` | Axis YOLO raises or returns invalid axes | Runs one CV+VLM recovery; returns a terminal failure if recovery is invalid | `metadata.axis_detection` records `axis_yolo` as primary, `cv_vlm_axes` as fallback, trigger status, bounded errors, and the selected method | Valid recovered axes continue to foreground extraction | recovery |
| Stage 3 foreground model | `src/matdeplot/pipeline.py::MatDeplotPipeline.extract` around `get_line_prob_multiscale(...)` | Foreground inference raises | Returns `_failed_result(...)` with `success=False` | `ExtractionResult.failures[-1].stage=="foreground"` and `exception_type` is preserved | Extraction ends before curve counting and separation | terminal |
| Stage 3 foreground pixel selection | `src/matdeplot/pipeline.py::MatDeplotPipeline.extract` plus `src/matdeplot/separation.py::prepare_pixel_mask` | `foreground_fraction < foreground.fallback_fraction`, with `foreground.fallback_fraction=0.003` | Sets `used_fallback=True` and switches from the foreground mask to `valid_region & (gray < 240)` before morphology | `ExtractionResult.used_fallback=True`; `ExtractionResult.foreground_fraction` records the measured fraction | Curve separation still runs on a deterministic non-white-pixel mask | recovery |
| Stage 3 curve count provider | `src/matdeplot/pipeline.py::MatDeplotPipeline.extract` around `_resolve_curve_count(...)` | Explicit/cached/Gemini curve-count resolution raises | Records the original failure, then runs `silhouette_curve_count(...)`, and wraps the result with the original exception text as `fallback_reason` | Appends `FailureRecord(stage="curve_count", ...)`; `ExtractionResult.curve_count_source=="silhouette"`; `metadata["curve_count_fallback_reason"]` stores `<ExceptionType>: <message>` | Separation continues with a deterministic local curve-count fallback | recovery |
| Stage 3 silhouette local fallback | `src/matdeplot/curve_count.py::silhouette_curve_count` | Too few valid foreground pixels | Returns a local `CurveCountResult` instead of raising | `CurveCountResult.source=="silhouette"` and `fallback_reason=="too_few_foreground_pixels"` | Extraction keeps a deterministic count outcome rather than crashing in this tested low-pixel case | recovery |
| Stage 3 calibration | `src/matdeplot/calibration.py::calibrate_axes` | Normal OCR output contains fewer than two valid numeric ticks on an axis | Generates six `equidistant_ticks` for that axis and calibrates with them | `metadata.calibration` records the primary tick count, selected method, and `synthetic_ticks_used` | Pixel and real-coordinate curves remain available | recovery |
| Stage 3 calibration | `src/matdeplot/pipeline.py::MatDeplotPipeline.extract` around `calibrate_axes(...)` | PaddleOCR initialization or execution raises, or calibration remains unavailable | Records a calibration failure but still keeps extracted pixel polylines; `real_points` become empty | Appends `FailureRecord(stage="calibration", ...)`; each `CurveRecord.pixel_points` is preserved; `CurveRecord.real_points=[]` | Pixel-space output remains available while real-axis values are withheld | recovery |
| Stage 3 per-curve abstention | `src/matdeplot/pipeline.py::MatDeplotPipeline.extract` | `confidence < abstention.threshold`, with `abstention.threshold=0.3` | Keeps the curve record and marks it as abstained | `CurveRecord.abstain=True`; `CurveRecord.confidence` stores the low value | Downstream consumers can filter or review low-confidence curves instead of treating them as verified | abstention |
| Stage 3 query retention guard | `src/matdeplot/foreground.py::get_line_binary_mask` | No query has `objectness > obj_threshold` | Keeps the max-objectness query via `keep = obj_prob >= obj_prob.max()` instead of returning an empty union | No separate record field is emitted; the effect is internal to the foreground probability/mask | Foreground inference still returns a deterministic mask/probability surface | recovery |
| Stage 4 optional judge | `src/matdeplot/document_pipeline.py::DocumentPipeline.run` | `extraction_failed` | Records a structured judge failure with no judge call and admitted false | `judge.error="extraction_failed"`; `admitted=false` | Document processing continues and raw extraction outputs are still written | fail-closed |
| Stage 4 optional judge | `src/matdeplot/document_pipeline.py::DocumentPipeline.run` | calibrated curves unavailable | Records a structured judge failure with no judge call and admitted false | `judge.error="calibrated_curves_unavailable"`; `admitted=false` | Document processing continues and raw extraction outputs are still written | fail-closed |
| Stage 4 optional judge | `src/matdeplot/document_pipeline.py::DocumentPipeline.run` and `src/matdeplot/judge.py::parse_judge_response` | provider/parse/unexpected judge failure | Returns a structured error fail-closed verdict; document continues | `judge.error` records the failure class; `admitted=false` | The manifest is still produced even when the hosted judge fails operationally | fail-closed |
| Stage 4 optional judge | `src/matdeplot/judge.py::parse_judge_response` | three-criterion gate | admitted true iff all three literal true | `curve_count_match`, `shape_match`, and `range_plausible` must each be the literal boolean `true`; `shape_match` includes substantial extraction artifacts | The judge acts as a quality-control admission filter, not a best-effort scorer | admission gate |

## Scope boundary

The tests confirm that these branches execute as described. They do not show
that fallback output is more accurate than the primary path or establish an
overall accuracy gain. Judge responses, verdict logs, and accepted manifests
are not included.
